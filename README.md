# Metro Cimahi Motor

Situs katalog motor Yamaha untuk showroom fiktif di Cimahi. Proyek portofolio.

**Lihat situsnya:** https://eternaledo.github.io/metro-cimahi-motor

## Isi situs

- Beranda dengan hero panel per kategori, koleksi motor, layanan, dan FAQ
- Katalog dengan filter kategori, transmisi, kapasitas mesin, dan harga
- Detail motor: varian dan harga, pilihan warna, fitur, dan tabel spesifikasi
- Bandingkan hingga tiga motor berdampingan
- Daftar dealer dan artikel seputar motor Yamaha

## Tentang versi ini

Aplikasi aslinya dibuat dengan Laravel 12, MySQL, Blade, Tailwind CSS, dan Alpine.js, lengkap dengan
panel admin, login, dan pemesanan test ride. Repo ini berisi versi statis halaman pengunjungnya
untuk GitHub Pages. Filter katalog dan perbandingan berjalan di browser, dan form pertanyaan
hanya contoh (tidak mengirim data).

Harga, dealer, alamat, dan kontak hanyalah contoh. Proyek ini tidak berafiliasi dengan
PT Yamaha Indonesia Motor Manufacturing. Merek dan foto produk milik pemiliknya masing-masing.
